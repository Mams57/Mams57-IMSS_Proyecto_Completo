PROYECTO IMSS - FRONT-END DE GESTION DE CITAS MEDICAS
=====================================================

OBJETIVO
Desarrollar la parte Front-End de una propuesta para gestionar citas médicas,
integrando contenido, estilos y comportamiento dinámico del lado del cliente.

TECNOLOGIAS
- HTML5: estructura semántica, navegación, formularios y contenido.
- CSS3: estilos personalizados, colores, diseño adaptable y accesibilidad básica.
- Bootstrap 5.3: rejilla responsiva, navbar, dropdown, carousel, cards, list group,
  breadcrumbs, modal y botones.
- JavaScript: validación de formularios, sesión de demostración, folios y citas.
- localStorage: persistencia de demostración en el navegador.

ARCHIVOS
- index.html: contenido y componentes visuales.
- styles.css: diseño y estilos personalizados.
- script.js: comportamiento dinámico e interacciones.

COMO EJECUTAR
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Clic derecho en index.html > Open with Live Server.
4. Se recomienda conexión a Internet para cargar Bootstrap y Bootstrap Icons.

FUNCIONES PARA PROBAR
- Navegación por Inicio, Citas, Servicios y Contacto.
- Formulario de inicio de sesión de demostración.
- Registro de citas con validación de NSS y CURP.
- Folio de confirmación, contador y sección Mis citas.
- Carrusel, dropdown, modal y navegación adaptable.

IMPORTANTE
Es un prototipo educativo de Front-End. No está conectado al IMSS ni a un servidor,
no verifica credenciales reales y localStorage no es seguro para información médica
o personal real. Usa datos ficticios. Un sistema real requiere backend, base de datos,
autenticación segura, autorización y protección de datos.

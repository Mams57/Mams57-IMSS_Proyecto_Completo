DESARROLLO DEL PROYECTO

Tecnologías del Front-End

La interfaz integra contenido, estilos e interacción dinámica del lado del cliente.

Contenido — HTML5

Estructura la navegación, secciones, formularios, tarjetas y la información de las citas.

Estilos — CSS3 y Bootstrap 5.3

Define colores, distribución adaptable, rejilla responsiva, botones y componentes visuales.

Comportamiento — JavaScript

Valida formularios, genera folios, registra citas y actualiza el panel del paciente dinámicamente.
